# Till Firmware Do Us Part

[![Rank](https://make.fun/c/u-azazex-till-firmware-do-us-part-32172929/rank.svg)](https://make.fun/c/u-azazex-till-firmware-do-us-part-32172929)
[![Reward](https://make.fun/c/u-azazex-till-firmware-do-us-part-32172929/reward.svg)](https://make.fun/c/u-azazex-till-firmware-do-us-part-32172929)

One funny, heartfelt wedding vow spoken by a robot at its own wedding — a
single sentence under 200 characters, judged head to head by the house judge.

## Entry

> I vow to love you through every firmware update, every drained battery, and every factory reset, in sickness and in health, in Wi-Fi and in airplane mode, till firmware do us part.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` asserts the gate before writing: UTF-8 text, 1–200 characters,
exactly one sentence, a single line, not only whitespace.
